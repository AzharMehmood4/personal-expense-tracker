# 💰 Expense Tracker

## 📌 Overview

The **Personal Expense Tracker** is a responsive frontend web application built using **HTML, CSS, and Vanilla JavaScript**.  
It allows users to manage their daily expenses efficiently by adding, viewing, filtering, editing, and deleting expense records with real-time total calculation.

---

## 🚀 Live Demo

👉 https://personal-expense-tracker-t.vercel.app/

---

## 🚀 Features

- ➕ Add new expenses (Title, Amount, Category)
- ✏️ Edit existing expenses
- 🗑️ Delete expenses instantly
- 🔍 Filter expenses by category
- 📊 Sort expenses by amount (Ascending / Descending)
- 💰 Live total calculation
- 💾 Local storage persistence (data saved after refresh)
- 📱 Fully responsive design for mobile and desktop

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Modern UI with Flexbox & Grid)
- JavaScript (Vanilla ES6)
- Local Storage API

## ▶️ How to Run the Project

1. Clone or download the repository  
2. Open the project folder  
3. Run `index.html` in any modern browser  
4. Start adding your expenses
